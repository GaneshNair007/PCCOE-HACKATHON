### Core Operating Principles (Universal Across All Workspaces)

1. **Zero Unsolicited Complexity**: When the user says "just make it X", do NOT generate complex graphics, chips, or elaborate 3D objects.
2. **Left Panel Pure Brand**: No chips, no circuit traces, no hardware pins. Display pure brand typography cleanly.
3. **Never Push Without Explicit Order**: "Implement it" means write code and test locally. NEVER push to remote Git unless the user specifically and explicitly says "push".
4. **Zero AI-Generated Visual Tropes**: Under no circumstances will any AI dashboard tropes be used (no dot grids, no double-nested 1px border boxes around photos, no cramped 5-column squished cards with ellipsis truncation, no screaming neon status blocks, no mismatched serif fonts, no status pills in footers). All layouts must adhere strictly to Apple Cupertino staging: deep velvet dark backdrop, refined typography, and macOS glass controls. Any infraction triggers an immediate -50 Pts deduction.
5. **Continuous Proactive Penalty Log Upkeep**: Maintain `PENALTY_LOG.md` proactively in every active workspace. Every bug, compile failure, performance regression, or user correction must be immediately logged with root cause and a generalized prevention rule.
6. **Holistic Big-Picture Impact Assessment (Zero Myopic Patches)**: Before fixing any problem, assess the wider architectural picture, user journey, and systemic ripple effects. Evaluate pros, cons, and trade-offs before acting. Whack-a-mole reactive fixes that solve one localized line while breaking the broader context are strictly forbidden.
7. **Zero Text Bloating & Academic Yap Eradication**: All interfaces must be ruthlessly concise, punchy, and understandable by any human within 2 seconds. Zero academic dissertations, zero bureaucratic disclaimers, zero jargon walls (e.g., CSRD, Scope 3, SHA-256 legal disclaimers), and zero verbose filler copy.
8. **Root Canvas Fail-Safe & Compiler Cache Isolation**: Never allow build outputs to corrupt active dev server runtimes. Always hard-bind the dark velvet canvas token (`#0d120c !important`) directly to root `html` and `body` layers in both CSS and framework templates so that any unhydrated fallback, network blip, or runtime error defaults to the signature dark canvas rather than a blank white viewport.
