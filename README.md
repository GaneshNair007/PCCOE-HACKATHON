# ⚡ CARBONERRA — AI-Powered Predictive Carbon Optimization Platform
> **PCCOE Hackathon Project Submission**

🌐 **Live Deployment**: [https://pccoe-hackathon.vercel.app](https://pccoe-hackathon.vercel.app)

Carbonerra is a modern, executive-grade AI-powered digital sustainability telemetry and predictive carbon optimization platform for websites and enterprise web applications.

---

## 🌟 Key Platform Features & Telemetry

1. **Overview Dashboard**:
   - EcoScore Gauge Index (`A+`, `0.24 g CO2e / view`)
   - Annualized Environmental Impact (`14.2 Trees / Year`, `312 kWh`, `1,280 Car Miles Saved`)
   - Verified Green Hosting Attestation (`AWS us-east-1`, 100% renewable wind & solar)
   - Real-Time URL Audit Scanner Bar
   - Page Weight & Payload Breakdown stacked visualizer (`1.85 MB`)
   - 3-Column Resource Cards with blur-reveal quick AI fix triggers

2. **What-If Carbon Physics Simulator ("Carbon Lab")**:
   - Interactive sliders for Image AVIF/WebP Compression (`0-100%`), JS Deferral & Tree-Shaking (`0-100%`), Browser Cache Retention (`1-365 Days`), and 100% Renewable Green Hosting Grid Toggle.
   - Live Physics Comparison Engine: Baseline (`0.58g`) vs Target (`0.19g CO2e`), `-67.2%` Carbon Reduction Callout.
   - `[ APPLY TO BUDGET ]` and `[ EXPORT PR FIX PATCH ]` automated workflow CTAs.

3. **ML Predictive Trajectory & Forecasts**:
   - Chart.js multi-scenario line chart (`1M`, `6M`, `12M`, `24M` timeframes across Expected, Aggressive, and Conservative growth models).
   - Trajectory Warning Alert trigger (`4.8 Metric Tons CO2 / Year threshold alert`).

4. **AI Recommendation & Fix Hub**:
   - Framer-style AI prompt command bar.
   - Priority-sorted action cards (`P0 CRITICAL`, `P1 RECOMMENDED`, `P2 POLISH`).
   - Plain-language cause explanations & JetBrains Mono code solution drawers (`<picture>` AVIF/WebP patch).
   - 1-Click PR patch generator.

5. **Carbon Budget & Regression Shield**:
   - Policy Ceiling Slider (`0.30 g CO2 / page floor`).
   - Regression Incident Alert card for Commit `#f8a192` (+22% carbon increase).
   - Interactive before/after Git Diff View (`package.json`, `index.html`).
   - CI/CD build block and 1-click AI revert triggers.

## 🎨 Design System Specifications

- **Color Palette**: Deep Forest (`#01472e`), Sage (`#ccd5ae`), Olive (`#e9edc9`), Cream (`#fefae0`), Moss (`#a3b18a`), Accent Neon Lime (`#cbff00`).
- **Typography**: Display font **Anton** (`23vw` hero title, `15vw` section headers) paired with tracked-out **Inter** (`0.2em - 0.4em` tracking) and **JetBrains Mono**.
- **Texture**: Persistent 4% opacity SVG fractal noise overlay across the viewport.
- **Geometry**: `border-radius: 5rem` for large sections, `border-radius: 2.5rem` for cards, `border-radius: 3rem` for floating hero eco-cards.
- **Motion Signature**: Smooth `cubic-bezier(0.16, 1, 0.3, 1)` reveals over 1.2s, `@keyframes float` animations, and depth scroll parallax.

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/GaneshNair007/PCCOE-HACKATHON.git
cd PCCOE-HACKATHON

# Switch to the feature branch
git checkout feature/carbonerra-platform

# Start local server
python3 server.py
```

Then open **`http://localhost:8082`** in any web browser.
